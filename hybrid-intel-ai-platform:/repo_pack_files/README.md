# Hybrid Intelligence Analysis Platform

A portfolio project demonstrating how human-derived and technical reporting can be transformed into an AI-enriched graph for analyst decision support.

## What this project does

This system ingests structured reporting from three CSV inputs:

- `data/entities.csv`
- `data/reports.csv`
- `data/edges.csv`

It then runs an AI-style enrichment pipeline to produce:

- `output/reports_enriched.csv`
- `output/entities_enriched.csv`
- `output/unified_graph_ai.json`

The Streamlit dashboard reads the generated JSON artifact and visualizes:

- threat prioritization
- link analysis
- geospatial activity
- node detail and supporting reports
- graph metadata

## Why this project matters

This project is designed to show:

- cloud and data pipeline thinking
- operational problem solving under uncertainty
- AI-assisted report enrichment
- entity extraction and semantic relationship modeling
- analyst-focused interface design

## AI capabilities included

The enrichment pipeline adds:

- extractive summarization
- entity extraction
- semantic similarity links between reports
- anomaly scoring
- AI-adjusted threat scores
- a unified graph artifact for downstream consumption

## Run locally

### 1. Create a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
```

On Windows:

```bash
.venv\Scripts\activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Generate the AI-enriched graph

```bash
python ai_enrichment_pipeline.py
```

### 4. Launch the dashboard

```bash
streamlit run app/hybrid_intel_dashboard_from_json.py
```

## How the pipeline works

```text
CSV Inputs -> AI Enrichment Pipeline -> unified_graph_ai.json -> Streamlit Dashboard
```

## Expected input files

### `entities.csv`
Contains the base entity list with fields such as:
- `name`
- `type`
- `threat_score`
- `confidence`
- `mentions`
- `last_seen`
- `primary_location`
- `status`

### `reports.csv`
Contains reporting inputs with fields such as:
- `report_id`
- `date`
- `source_type`
- `confidence`
- `location`
- `excerpt`
- `entities`
- `relevance`

### `edges.csv`
Contains relationships with fields such as:
- `source`
- `target`
- `relationship`
- `weight`

## Output artifacts

### `output/unified_graph_ai.json`
Primary dashboard artifact. This file is generated by the pipeline and used by the Streamlit app as the default source of truth.

### `output/reports_enriched.csv`
Report-level AI enrichment output, including generated summaries, expanded entities, and anomaly scores.

### `output/entities_enriched.csv`
Entity-level output with AI-adjusted threat scoring.

## Suggested demo narrative

This platform ingests human and technical reporting, enriches the data with AI-assisted summarization and entity extraction, infers semantic links across reports, and generates a unified graph used to support analyst prioritization and operational decision-making.

## Notes for GitHub and Streamlit deployment

For portfolio and recruiting purposes, it is useful to commit a sample `output/unified_graph_ai.json` so reviewers can run the dashboard immediately without needing to regenerate outputs first.

The dashboard is configured to:
1. prefer `output/unified_graph_ai.json`
2. fall back to `data/unified_graph.json`
3. fall back to bundled sample data
